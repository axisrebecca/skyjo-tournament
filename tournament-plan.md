# Skyjo Tournament Plan

## Constraints this plan is built around

- Fixed pool of participants (~10-15, possibly more), but not everyone attends every week.
- 1 session per week, about 30 minutes per session.
- 8 persons per game, which will be seeded and placed.
- Season length: ???
- Format: one-shot variant (single round, no play-to-100).

## Weekly session format

One session per week, where people show up. If **8 or fewer** people show up: everyone plays. If **more than 8** show up, for each game 8 seats are filled using the rotation rule below; the rest sit out that game.

During ??? weeks there will be a qualification to the final. For each game played, the top three will get game points for the leaderboard. When everyone has played XX games, the top 4 will be selected for a finale.

If there is a tie of people with the same score to be selected to the finale or not, the person with the most wins is selected. If the number of wins are equal, it is the number of second places that counts and so far. If it still is equal, the lower total number of points collected during the games will be selected.

## Fair rotation

There will be a counter on games played per person across the season. If there are more than 8 present at a session, the game setup will select who will play, and prioritze the people with the fewest games played so far, and the rest at random.

The system will also place people in random order for each game, to make sure there is a shuffle and you don't sit next to the same people for multiple games.

## Scoring system

Score is fixed and do not consider how many that were playing in the game.
Players agree who ended the game and apply any required doubling before entering the final scores.

1.  st place gets 10 points
2.  nd place gets 5 points
3.  rd place gets 2 point.
4.  The rest gets 0 points.

Tied scores share a place and skip the following places. For example, a tie for first produces places 1, 1, 3. Each tied player gets the leaderboard points for the shared place.
